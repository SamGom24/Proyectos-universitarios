Descripción:
Aquí se especifica las extensiones a instalar para poner en funcionamiento la aplicación web en Visual Studio Code:

1. JavaScript (ES6) code snippets: Esta extensión añade autocompletado y fragmentos de código modernos de JavaScript. Se utilizó para
evitar errores como olvidar llaves, paréntesis, comillas o escribir mal palabras clave. Además, agiliza la escritura de cabeceras de
funciones y/o clases.

2. Live Server: Esta extensión se encarga de crear un servidor local y utiliza el fichero index.html como página principal. Cada
cambio que se haga en cualquiera de los archivos del proyecto (index.html, sketch.js, style.css), lo detecta y recarga la web con 
los cambios aplicados.

3. Prettier - Code formatter: Esta extensión formatea automáticamente el código para mantenerlo limpio y consistente. Esta extensión es
realmente opcional de instalar, ya que no afecta en nada a la ejecución del código principal. Simplemente se usó para indentar bien las 
líneas, alinear correctamente las llaves ({}) y arreglar espacios entre palabras.

Una vez instaladas estas extensiones, para lanzar el servidor y ejecutar la aplicación, se deberá presionar el botón "Go live" (normalmente se
encuentra en la esquina inferior derecha) y se abrirá una ventana de navegador (en local) donde estará todo el contenido de la aplicación.
